One correlated request

The Agent goes out. The command comes back.

The persistent connection is initiated from inside the broker network. When Web requests a report, API routes it to the preferred or selected Agent and waits for the correlated result.

  • ✓ WebSocket over the existing HTTPS port
  • ✓ Request IDs, timeout, and bounded concurrency
  • ✓ No inbound Agent listener
  • ✓ Results discarded after the response
