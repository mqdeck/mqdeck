Simple by design

From inventory to current facts in three steps.

MQDeck keeps the idle path quiet. Operators decide when live broker data should be collected.

01
REGISTER

Describe each broker once.

Add the endpoint, tags, and preferred Worker to a small YAML inventory. Browsing the inventory does not contact the broker.

02
W
CONNECT

Let the Worker call out.

The Worker opens one authenticated WebSocket to the API. No inbound Worker port is required.

03
INSPECT

Collect only when needed.

Open a broker, queue, or channel to request current facts. Queue Watch starts and stops explicitly.

One correlated request

The Worker goes out. The command comes back.

The persistent connection is initiated from inside the broker network. When Web requests a report, API routes it to the preferred or selected Worker and waits for the correlated result. An optional local model sits with the API and receives a report only when an operator asks the assistant.

  • ✓ WebSocket over the existing HTTPS port
  • ✓ Request IDs, timeout, and bounded concurrency
  • ✓ No inbound Worker listener
  • ✓ Results discarded after the response

API on RHEL
MQDECK_VERSION=1.0.5 # MQDECK_VERSION
API_VERSION=1.0.35 # MQDECK_API_VERSION
curl -fLO "https://github.com/mqdeck/mqdeck/releases/download/v${MQDECK_VERSION}/mqdeck-api_${API_VERSION}_linux_amd64.tar.gz"
tar -xzf "mqdeck-api_${API_VERSION}_linux_amd64.tar.gz"
cd "mqdeck-api_${API_VERSION}_linux_amd64"
sudo ./install-api.sh
sudo systemctl enable --now mqdeck-api
Worker on RHEL
MQDECK_VERSION=1.0.5 # MQDECK_VERSION
WORKER_VERSION=1.0.34 # MQDECK_WORKER_VERSION
curl -fLO "https://github.com/mqdeck/mqdeck/releases/download/v${MQDECK_VERSION}/mqdeck-worker_${WORKER_VERSION}_linux_amd64.tar.gz"
tar -xzf "mqdeck-worker_${WORKER_VERSION}_linux_amd64.tar.gz"
cd "mqdeck-worker_${WORKER_VERSION}_linux_amd64"
sudo ./install-worker.sh
sudo systemctl enable --now mqdeck-worker
Web on RHEL
MQDECK_VERSION=1.0.5 # MQDECK_VERSION
WEB_VERSION=1.0.40 # MQDECK_WEB_VERSION
curl -fLO "https://github.com/mqdeck/mqdeck/releases/download/v${MQDECK_VERSION}/mqdeck-web_${WEB_VERSION}_standalone.tar.gz"
tar -xzf "mqdeck-web_${WEB_VERSION}_standalone.tar.gz"
cd "mqdeck-web_${WEB_VERSION}_standalone"
sudo ./install-web.sh
sudo systemctl enable --now mqdeck-web
